# HRMS

Human Resource Management System: employees, attendance, leave, and payroll inputs, with role-based access.

## Layout

```
HRMS/
├── .cursor/rules/     Cursor agent conventions
├── docs/              Requirements, plan, implementation log
├── client/            Frontend (not initialized yet)
├── server/            API (not initialized yet)
├── .env.example       Environment variable template
└── README.md
```

## Docs

| File | Purpose |
|------|---------|
| [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) | Product scope |
| [docs/PLAN.md](docs/PLAN.md) | Build sequence |
| [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md) | What has been built |

## Setup

1. Copy `.env.example` to `.env` and set values.
2. Client and server apps will be added in later phases (see the plan).

Do not commit `.env`.
